# 2026 东方project 国人专辑一览

一份收录 2026 年东方 Project 国内社团与个人同人音乐新作的鉴赏清单。

## 内容

- 共收录 37 张专辑，信息包含专辑名、社团 / 个人、发布月份、价格、是否实体版、曲目数等
- 37 张专辑均带封面，展示于 `covers/` 目录
- 每张专辑附有简评，以及 Bilibili 试听、dizzylab 购买链接
- 支持按月份分组浏览、搜索、筛选与排序
- 首页提供 2026 / 2027 年份入口，2027 暂为筹备中

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 年份入口，选择 2026 / 2027 |
| `2026东方project国人专辑一览.html` | 网页主页面（夜晚主题、流星特效、搜索/筛选/排序） |
| `2026东方project国内社团与个人音乐专辑一览.png` | 信息图（图片版，37 张） |
| `covers/` | 37 张专辑封面 |
| `表格/` | 原始数据表格 |

## 查看方式

打开 `index.html` 先选择年份；也可以直接打开 `2026东方project国人专辑一览.html` 浏览。如果启用 GitHub Pages，访问仓库主页会先进入年份入口。

也可以在线表格形式查看：[腾讯文档](https://docs.qq.com/sheet/DWG95eHhTZGNpS0Rn?tab=BB08J2)
